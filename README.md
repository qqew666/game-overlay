# GameOverlay

Оверлей поверх игр: показывает **FPS** и **пинг** до выбранного сервера.
Написан на Rust: Win32/GDI+, image (JPEG), reqwest с системным TLS Windows.

## Версия 1.5.0

- Полностью новая бежевая панель, коричневые акценты без синего.
- Встроенный портрет Mimi (персонаж Typh), включая небольшое изображение в оверлее.
- Общая геометрия отрисовки и нажатий, никаких перекрывающихся кнопок.
- Нажатие с захватом мыши; отпускание вне кнопки отменяет действие.
- Tab / Shift+Tab переключают фокус, Enter / пробел нажимают кнопку, Esc сворачивает в трей.
- Меню автоматически уменьшается под рабочую область маленького экрана.
- Стрелки выбора пинга доступны для всех целей, включая пятую и последующие.
- Обновление скачивает отдельный EXE (или MSI старого релиза); запуск требует второго нажатия.
- Самостоятельный `GameOverlay.exe`: распаковка и отдельные картинки не нужны.

## Возможности

- Прозрачное окно поверх игры с настоящей альфой (`UpdateLayeredWindow`):
  скруглённая карточка, мягкая тень, никакого квадратного фона; клики проходят
  сквозь оверлей, фокус не перехватывается
- Отрисовка через GDI+ с антиалиасингом: крупные цифры, цвет по порогам
  (зелёный / жёлтый / оранжевый / красный), градиентная полоса-акцент
- Крупная карточка 400×190 с запасом по полям: заголовок с именем активной
  игры, крупные FPS и PING, время кадра, цель пинга
- Панель управления — обычное окно приложения, без консоли: живые показатели,
  переключатели (автозапуск, слежение за окном, видимость), список целей,
  кнопки выхода и перезапуска от администратора. Закрытие окна сворачивает
  программу в трей, оверлей продолжает работать
- Оверлей убирается кнопкой «Убрать оверлей» в панели (или клавишей `F1`) и
  возвращается той же кнопкой; размер переключается 80 / 100 / 125 / 150 %,
  применяется сразу и запоминается в `HKCU\Software\mimi(typh)\GameOverlay`
- Точный FPS игры: считаются вызовы `Present` конкретного процесса из
  ETW-провайдера `Microsoft-Windows-DXGI` — это собственный кадровый темп
  игры, а не частота композитора DWM
- Портрет Mimi встроен в EXE и отображается в панели и оверлее
- График пинга за последнюю минуту и точка на последнем замере
- Пинг с десятыми долями ниже 10 мс: 0.4 мс и 3.7 мс — разные маршруты
- Два метода замера: ICMP echo через raw-сокет (свой заголовок + контрольная
  сумма) и TCP-замер времени установления соединения (авто-откат, если ICMP режут)
- Несколько целей пинга с переключением по горячей клавише
- Оверлей следует за окном активной игры
- Автозапуск с Windows: запись в `HKCU\...\Run`, переключается клавишей `F6`
  или флагами CLI, установщик ставит её сразу
- Установщик MSI (WiX 5) с мастером установки, лицензией, ярлыками в меню
  «Пуск» и на рабочем столе

## Установка

Скачать **GameOverlay.exe** и запустить на Windows 10/11 x64. Ничего распаковывать не нужно.
Картинка Mimi включена в исполняемый файл. Автозапуск по желанию включается в панели.
Для точного FPS используется запуск от администратора; базовый режим показывает счётчик DWM.

## Использование

```
GameOverlay.exe                          # пинг до 1.1.1.1:443 (ICMP)
GameOverlay.exe --host game.example.com  # конкретный сервер
GameOverlay.exe --port 25565             # порт для TCP-замера
GameOverlay.exe --targets "1.1.1.1:443,8.8.8.8:53"   # несколько целей
GameOverlay.exe --mode tcp               # только TCP-замер
GameOverlay.exe --fixed-position         # не следовать за окном игры
GameOverlay.exe --autostart              # включить автозапуск и запуститься
GameOverlay.exe --no-autostart           # выключить автозапуск
GameOverlay.exe --autostart-status       # показать состояние автозапуска
GameOverlay.exe --tray-quiet             # запуск без панели, сразу в трей
GameOverlay.exe --verbose                # писать FPS/пинг в overlay.log
```

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `F1` | показать / скрыть оверлей |
| `F2` / `F3` | следующая / предыдущая цель пинга |
| `F4` | следовать за окном игры / фиксированная позиция |
| `F6` | включить / выключить автозапуск |
| `End` | выход |

## Как считаются метрики

**FPS** — основной источник: realtime-сессия ETW на провайдере
`Microsoft-Windows-DXGI` (`{CA11C036-0102-4A2D-A6AD-F03CFED5D3C9}`). Считаются
события `Present_Start` (42) и `PresentMultiplaneOverlay_Start` (178) того
процесса, чьё окно сейчас в фокусе, — это реальный кадровый темп игры, без
ограничения частотой монитора и без внедрения в процесс.

Запуск такой сессии требует прав администратора (или членства в группе
«Performance Log Users»). Если прав нет, оверлей работает в базовом режиме:
берёт глобальные счётчики `cDXPresentSubmitted` / `cFrameSubmitted` из
`DwmGetCompositionTimingInfo` и пишет об этом в панели и в карточке. Глобальный
счётчик описывает композитор, а не игру, и на рабочем столе стоит на ~10 —
именно это и видел прошлый релиз.

Кнопка **«Точный FPS (админ)»** в панели перезапускает программу с повышением
прав и переключает на первый режим.

**Пинг** — ICMP echo request через raw-сокет (`SOCK_RAW`, `IPPROTO_ICMP`):
заголовок ICMP (type 8, code 0, id, sequence) + контрольная сумма + payload,
ответ разбирается из `recvfrom` (в ответе Windows приходит полный IP-пакет,
ICMP-заголовок лежит за `IHL`-байтами IP-заголовка). RTT считается по
`QueryPerformanceCounter`. Если сеть блокирует ICMP — автоматический откат
на TCP-connect.

## Ограничения

- Оверлей отрисовывается GDI+ и виден в оконном / borderless-режиме. В
  эксклюзивном fullscreen его перекрывает сама игра — переключите игру в
  borderless (Alt+Enter) или оконный режим. Там же не растут счётчики DWM,
  поэтому FPS в эксклюзивном fullscreen не измеряется.
- ICMP через raw-сокет работает без повышения прав на Windows 10/11.

## Сборка из исходников

```powershell
# Установить Rust через https://rustup.rs
powershell -ExecutionPolicy Bypass -File .\build.ps1
# Результат: dist\GameOverlay.exe
```

Проверка на Windows: `cargo test --locked`. Чистые тесты геометрии на Linux:
`rustc --edition 2021 --test src/layout.rs -o layout-tests && ./layout-tests`.

## Структура

```
src/main.rs       CLI, потоки замера, скрытие консоли
src/overlay.rs    окно, отрисовка GDI+, Mimi, график, горячие клавиши, FPS
src/ping.rs       ICMP (raw-сокет) и TCP-замер пинга
src/autostart.rs  автозапуск через HKCU Run
installer/        WiX-исходник установщика, иконка, лицензия, README
build.ps1         сборка отдельного portable EXE
```
