GameOverlay 1.1
================

Небольшой оверлей поверх игр: показывает текущий FPS и пинг (время отклика)
до выбранного сервера. Скруглённая карточка с настоящей прозрачностью,
крупные цифры с цветом по порогам, график пинга за минуту и бойкиссер в углу.

Установка
---------
GameOverlay-1.1.0-x64.msi  — установщик с мастером (без прав администратора,
ставится в %LOCALAPPDATA%\Programs\GameOverlay, ярлык в меню "Пуск" и на
рабочем столе, автозапуск с Windows).
GameOverlay-1.1.0-portable.zip — распакованный вариант + тот же .msi.

Запуск
------
  GameOverlay.exe                        пинг до 1.1.1.1:443 (ICMP)
  GameOverlay.exe --host game.example.com --port 25565
  GameOverlay.exe --targets "1.1.1.1:443,8.8.8.8:53"   несколько целей
  GameOverlay.exe --mode tcp             только TCP-замер (без ICMP)
  GameOverlay.exe --fixed-position       не следовать за окном игры
  GameOverlay.exe --autostart            включить автозапуск
  GameOverlay.exe --no-autostart         выключить автозапуск
  GameOverlay.exe --autostart-status     проверить автозапуск
  GameOverlay.exe --verbose              печатать FPS/пинг в консоль

Горячие клавиши
---------------
  F1        показать / скрыть оверлей
  F2 / F3   следующая / предыдущая цель пинга
  F4        следовать за окном игры / фиксированная позиция
  F6        включить / выключить автозапуск
  End       выход

Автозапуск
----------
Запись в HKCU\Software\Microsoft\Windows\CurrentVersion\Run с ключом
--tray-quiet. Видна и отключается в Диспетчере задач -> Автозагрузка.
Права администратора не нужны, при удалении программы запись снимается.

Как считается FPS
-----------------
Через счётчики present'ов DWM (cDXPresentSubmitted). Это реальная частота
отрисовки DXGI-приложений в системе; в игре основной вклад даёт сама игра.
Важно: в настоящем эксклюзивном fullscreen игра рисует мимо композитора
DWM, и там счётчик не растёт — переключите игру в borderless (Alt+Enter) или
оконный режим. В borderless оверлей виден и FPS считается корректно.

Как считается пинг
------------------
ICMP echo request через raw-сокет (свой заголовок + контрольная сумма),
тайминг по QPC. Ниже 10 мс значение показывается с десятыми долями.
Если сеть режет ICMP — автоматический откат на TCP-замер времени
установления соединения с host:port.

Ограничения
-----------
- Оверлей рисуется средствами GDI+ поверх оконного/borderless-режима.
  В эксклюзивном fullscreen его перекрывает сама игра.
- ICMP через raw-сокет работает без прав администратора на Windows 10/11.
